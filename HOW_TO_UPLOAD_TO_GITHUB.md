# Publish this exact project-handoff folder on GitHub

Recommended target: use a **dedicated repository** to avoid mixing academic deliverables into the production codebase. If you prefer the existing public `corbelltony/cheddar-smart-hub` repository, add the entire `project-handoff` folder without replacing its website files.

1. Open the GitHub repository you choose, and go to its default branch.
2. Choose **Add file → Upload files**. Drag in the **contents of `project-handoff` with their folder structure intact**, or use `git add`, `git commit`, and `git push` from a normal local Git checkout to preserve the tree. Uploading a ZIP alone will not give a navigable index.
3. Confirm that the GitHub tree contains `project-handoff/README.md`, `project-handoff/index.html`, all PDFs, both showcase files, and `evidence/videos/`.
4. Open the folder's README and click each deliverable. For the HTML, use **Download raw** and open the file locally together with its sibling assets. Optionally enable GitHub Pages to serve it as a website.
5. Check the repository URL in an incognito/private window. A logged-out reviewer must be able to open the README and access the files; if it is private, grant the instructor access instead.
6. Review actual recording frames and audio for any personal or sensitive details before publishing publicly. Machine privacy scanning alone is insufficient.

If publishing into `cheddar-smart-hub`, the link to submit is `https://github.com/corbelltony/cheddar-smart-hub/tree/main/project-handoff` **only after the folder has actually been uploaded and verified**.
