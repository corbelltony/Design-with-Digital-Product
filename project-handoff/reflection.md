# Cheddar Hub — Reflection

The next person using Cheddar Hub could be another student, someone reviewing my project, or even myself six months from now. They need to understand what the system does, how to use it, and what still needs work. Balancing graduate school with a full-time corporate job, I know how valuable clear documentation can be when you don't have hours to figure something out. Throughout this project, I used Codex for coding and troubleshooting, Muse AI for visual elements, ChatGPT for documentation and organizing information, and Descript for video production. Each tool was useful, but none of them got everything right the first time.

One thing I noticed was how differently the same information worked depending on its presentation. Written documentation was better for detailed instructions, test results, and technical information. The infographic made understanding the system much faster, while the interactive overview made exploring features easier. However, the visual versions sometimes left out details that were important for troubleshooting.

I reused actual recordings, screenshots, development notes, and GitHub history. I also spent time correcting screenshots that didn't match the instructions, repositioning images, and fixing video captions that covered the screen. There are still limitations, especially voice response times and system reliability. Not every workflow has been independently retested. Moving forward, I'll continue using AI to help develop and document changes, but I'll verify results myself. Working in a corporate environment has taught me that documentation matters, but accurate documentation matters even more.
