## Portability and access

**Offline:** Keep the entire `project-handoff` folder together and open `index.html` (not `overview.html` unless you want the feature explorer). Files are linked by relative paths and require no localhost server. Browser PDF/MP4 handling depends on the viewer.

**GitHub:** The README and individual files should remain in the same folder; clicking file names in the repository opens or downloads them. **GitHub Pages is optional**, not required for the offline index.

**Source code privacy:** Technical history points to an existing development repository that may be private. All assignment deliverables and original media are included here so a reviewer does not need development-repo access to see the work.
